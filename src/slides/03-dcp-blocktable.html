DCP 核心机制 ①：GLM-5.3-Flash 虚拟块与异构 Cache 交错落盘

通过 dcp_sharded: list[bool] 区分 5 个 Cache Group：仅 Group 0 SFA 主 KV 按 DCP 交错切分，非归属 Rank 写 PAD_SLOT_ID (-1)

交错映射公式（SFA+DCP: I == block_size == 128）

virtual_block_size = 128 × DCP   |   vblock_offset = pos % virtual_block_size
target_dcp_rank = (vblock_offset // 128) % DCP  （非 Owner 写入 -1 跳过落盘）

GLM-5.3-Flash 的 dcp_sharded 异构分片契约

• Group 0 (SFA 512维主 KV)：dcp_sharded=True，单卡显存降至 1/DCP。
• Group 0/1 (KPool 4:1 + Tail) & Group 2~4 (KDA SSM)：dcp_sharded=False。
