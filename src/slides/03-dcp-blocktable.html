DCP ①：Virtual Block 与交错 Slot Mapping

默认切分所有 Attention KV Cache：通过 Virtual Block 跨卡交错落盘，非归属 Rank 写 -1

交错映射公式（Interleave Size I）

virtual_block_size = block_size × DCP  |  target_rank = ((pos % VBlock) // I) % DCP

Attention KV 默认全切分 (AttentionSpec.dcp_sharded = True)

Full Attention、MLA/SFA 主 KV 及 Indexer Cache 默认均按 DCP 交错切分；非序列增长状态（如 Mamba/线性层）按 Group 设为 False。
