PCP + DCP 叠加：算力与显存双重切分

在 TP × PCP 网格上复用进程组建 DCP（DCP = PCP 或 DCP = TP × PCP）

PCP 切计算，只有 DCP 切 KV Cache

• 逻辑 DCP 组按 flat_idx = tp_rank * PCP + pcp_rank 组建（先跨 PCP，再跨 TP）。
• Prefill 阶段仅满足 (pos // 128) % DCP == dcp_local_rank 的 Token 写入物理 Slot，其余写 -1。

[示例：TP=2, PCP=2, DCP=4]

TP Groups  : [0, 1], [2, 3]
PCP Groups : [0, 2], [1, 3]
Logical DCP: [0, 2, 1, 3] (PCP-first)
HCCL Sorted: [0, 1, 2, 3] (dcp_collective_rank_order)

Stacked Prefill：统一发送计划 + 掩码落盘

• 当前步新 KV：build_pcp_ordered_slot_mapping 按 padded_gather_idx 重排全局 Slot，过滤 Padding。
• 历史 Cached KV：基于 global_batch 生成统一的 DCP AllGather 发送上界，接收后按本分片区间切片消费。

Stacked Decode：两级融合归并 dcp_a2a_fused(tp, pcp)

• 若 DCP == PCP：同组 Q Heads 已一致，免 Gather Q，直接跨 PCP 归并 (O, LSE)。
• 若 DCP == TP × PCP：仅在 tp_group 内 Gather Q Heads，算完后由 dcp_a2a_fused(..., tp_group, pcp_group) 一步完成跨 TP Scatter 与跨 PCP LSE 归并！
