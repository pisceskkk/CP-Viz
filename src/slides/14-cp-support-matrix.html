vLLM-Ascend PCP & DCP 最新特性适配全景矩阵

基于最新 MRV2 架构实况（注：GQA 的 DCP 支持已按 RFC #21305 移除，GQA 仅支持 PCP）

1. Prefill Context Parallel (PCP) 支持矩阵

Attention 后端 / 代表模型 Basic PCP APC + Chunked Graph Mode Speculative Decoding P/D 分离 (Mooncake) KV Pool (AscendStore)
MLA (DeepSeek-V3 / R1)
SFA (GLM-5.2)
KDA + SFA/KPool (GLM-5.3-Flash / Kimi-K3.1)
DSA & DSA V4.1 (DeepSeek-V4 / V4.1)
GQA (Qwen3 系列)

2. Decode Context Parallel (DCP) 支持矩阵（A2 / A3 / 950PR & 950DT）

Attention 后端 拓扑约束 (Standalone / Stacked) Chunked + APC Graph Mode Speculative P/D 分离 & KV Pool PCP + DCP 叠加
MLA (DeepSeek-V3 / R1) TP % DCP == 0 或 DCP ∈ {PCP, TP×PCP}
SFA (GLM-5.2 / 5.3-Flash / K3.1) DCP == TP 或 DCP ∈ {PCP, TP×PCP}
GQA / MQA (Qwen3 等) 必须保持 DCP = 1（Draft 保持原生 TP）
