DCP 核心机制 ②：GLM-5.3-Flash Decode 局部稀疏注意力与 dcp_a2a_fused

Decode 绝不跨卡搬运 KV Cache：sparse_index_remap 映射本地 Top-K → 本地 1/DCP KV 计算 → Triton 打包 (O_j, FP32 LSE_j) 归并

GLM-5.3-Flash 动态算子流 · DCP Decode (MTP=5) 从 KPool 全局 Top-2051 到 sparse_index_remap 与 dcp_a2a_fused

1. sparse_index_remap 过滤

Replicated KPool 选出全局 Top-2051 后，Triton Kernel 将其过滤并重映射为属于本 DCP Rank 的物理 KV Slot 及可见长度。

2. 无损 LSE 打包 All-to-All

Triton 将局部 O_j [6B, 64, 512] 与 FP32 LSE_j（INT32 位保留或 Base-256 编码）打包为单次 all_to_all_single。

3. 数值稳定 LSE 加权归并

m = max_j(L_j),   w_j = exp(L_j - m)
O = Σ(w_j · O_j) / Σ w_j
