DCP ④：History / Current 拆流通信重叠

MTP 多 Token 因果 Decode 下，将历史 KV 的 All2All 通信与当前步 KV 计算并行

flowchart LR Q["Query Heads Gather"] --> H_ATTN["主流：History Attention
(本地 1/DCP 历史 KV)"] H_ATTN --> COMM["通信流：dcp_a2a_fused
(defer_combine=True 异步 All2All)"] H_ATTN --> C_ATTN["主流：Current Attention
(当前步新 Token KV)"] COMM --> MERGE["主流：fused_dcp_lse_combine
(一次性合并 History + Current)"] C_ATTN --> MERGE

1. 为什么要拆分？

MTP 验证携带 K+1 个因果 Token：历史 KV 已按 DCP 分片，而当前步新 KV 在本地完整持有。

2. 双流隐藏 All2All

在 cp_decode_comm_stream 上异步执行历史输出的 All-to-All，与主流 Current 计算重叠。

3. 单次 LSE 归一化

fused_dcp_lse_combine 将所有 History 分片与 Local Current 一次性加权归约，避免重复计数。
