DCP 核心机制 ④：History / Current 拆分与通信计算重叠

在 MTP 投机验证等多 Token 因果 Decode 场景下，将 DCP 分片的历史 KV 与本地当前步 KV 拆流并行

flowchart LR Q["Query Heads Gather"] --> H_ATTN["主流：History FIA
(对本地 1/DCP 历史 KV)"] H_ATTN --> COMM["通信流：dcp_a2a_fused
(defer_combine=True 异步 All2All)"] H_ATTN --> C_ATTN["主流：Current FIA
(对当前步新 Token 完整 KV)"] COMM --> MERGE["主流：fused_dcp_lse_combine
(一次性合并所有 History Ranks + Local Current)"] C_ATTN --> MERGE

为什么必须拆分？

MTP 验证时单请求携带 K+1 个因果 Query Token：历史 KV 已按 DCP 分散在各卡，而当前步新 Token KV 尚未跨卡切分。

双流重叠隐藏 All2All

在独立通信流 cp_decode_comm_stream 上执行历史输出的 Pack 与 All-to-All，与主流上的 Current Token FIA 完全并行。

单次归一化避免重复计数

fused_dcp_lse_combine 将接收缓冲区与 local_output / local_lse 一并归约，保证 Current KV 精确计数一次。
