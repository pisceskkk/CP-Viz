部署选型与未来演进规划

GLM-5.3-Flash 推荐部署拓扑与 vLLM-Ascend 下一步优化方向

1. GLM-5.3-Flash 典型部署拓扑

• PD 分离部署（1M 上下文推荐）：
  – Prefill 节点：DP1 + TP1 + PCP8 + EP8（16 个 DualChunk 并行 + KDA 64 Heads 与词表切到 8 卡，显著压降 TTFT）。
  – Decode 节点：DP8 + TP1 + PCP1 + EP8（配合 FULL_DECODE_ONLY + MTP5 + ReplaySSM）。
• 超长上下文混部（128K ~ 1M+）：
  – 开启 DCP（I == block_size == 128）消除主 KV 冗余。

2. 未来演进规划（Roadmap）

• KPool / 线性层下的 PCP Decode Request Sharding：
  – 支持跨 PCP Rank 的 Recurrent State 归属管理，解开当前 Decode Replicated 约束。
• BlockTable 对齐上游 vLLM #57169：
  – AscendBlockTables 收敛为 Manager-Block 粒度，Kernel-Block 映射下沉至 AttentionGroup。
• 算子融合与 Dynamic CP：
  – 拓展 dcp_q_replicate 与按序列长度动态组建 CP 通信组。

短序列 (4K ~ 32K)

优先标准 DP / TP，无需开启 CP。

中长序列 (32K ~ 256K)

开启 PCP 压降首字时延 TTFT。

超长序列 (128K ~ 1M+)

开启 DCP 或 PCP + DCP 释放 KV 容量。
