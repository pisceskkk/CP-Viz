PCP 核心机制 ①：MRV2 下的单步 Batch 生命周期

Scheduler 保持全局 Batch，Worker 侧通过 PCPManager + AscendPCPManager 完成切分与采样前恢复

flowchart LR G["1. Global Batch
(Scheduler 统一调度)"] --> P["2. partition_batch
(DualChunkSwap 拆为 2x 虚拟请求段)"] P --> R["3. _reorder_segments
(规范排序：Decodes 在前, Prefills 在后)"] R --> CTX["4. AscendPCPAttentionContext

(跨 PCP 同步 KV / 局部 Attention)"] FWD --> REST["6. restore_for_sampling
(按 hidden_restore_idx 恢复全局顺序)"]
01 · PARTITION

2x 虚拟请求展开

每个 Prefill 拆为 Head/Tail 两个独立 RankSegment，Buffer 容量 2 * max_num_reqs

02 · DUAL MAPS

双向互逆映射表

padded_gather_idx 对齐 KV Slot；hidden_restore_idx 还原全局 Token 顺序

03 · CONTEXT

双视图上下文注入

Attention 同时获取 Local Query 偏移与 Global BlockTable / Slot Mapping

04 · RESTORE

采样与投机边界还原

restore_for_sampling 在 Runner 边界恢复完整序列供 LM Head 与 Draft 使用
