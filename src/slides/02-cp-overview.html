PCP 与 DCP：算力切分 vs 显存切分

PCP 切分输入序列算力，DCP 复用现有进程组切分 Attention KV Cache 显存

PCP (Prefill Context Parallel) 切算力 · 降 TTFT

将长 Prefill 的输入 Query 序列按 DualChunkSwap 头尾对称切分到多卡并行计算，扩展 World Size 为 PCP × TP。

DCP (Decode Context Parallel) 切显存 · 降 TPOT

复用 PCP / TP 进程组，默认将所有 Attention 的 KV Cache（含 Full Attention、主 KV 与 Indexer）沿序列维度交错分片（1/DCP）。
