CP 特性总览：以 GLM-5.3-Flash 为锚点的算力与显存切分

45 层混合主干（mHC + 34 层 KDA 线性注意力 + 11 层 NoPE SFA / KPool 稀疏注意力 + 288 MoE）在 PCP & DCP 下的协同全景

PCP (Prefill Context Parallel) 算力切分 · 降低 TTFT

将长 Prefill 按 DualChunkSwap 切为 2x 虚拟请求段：KDA 按 TP×PCP 切 Head 并还原因果顺序，SFA+KPool 异步 Gather Key 并仅对本地 1/PCP Query 算稀疏注意力。

DCP (Decode Context Parallel) 显存切分 · 提升容量与 TPOT

复用 PCP / TP 进程组：KPool Indexer (4:1) 全量复制零通信直出 Top-2051，而占显存大头的 SFA 512维主 KV 按虚拟块跨卡交错分片（1/DCP），Decode 经 dcp_a2a_fused 归并。
