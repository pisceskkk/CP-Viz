PCP ⑤：显存挑战与 TP × PCP 权重切分

纯 PCP 下单卡默认复制权重与完整 KV Cache；通过跨 TP × PCP 联合切分常驻权重释放单卡 HBM

01 · EMBEDDING & LM HEAD

词表权重跨 TP × PCP 切分

enable_pcp_embedding_lmhead_weight_sharding = True（默认开启）：大词表 Embedding 与 LM Head 权重按 TP × PCP 联合切分，适用于所有 Attention 后端。

02 · ATTENTION O_PROJ

o_proj 跨 PCP 权重/激活切分

enable_pcp_o_proj_weight_sharding = True（SFA/DSA 默认开启）：支持 TP=1 下临时 AllGather weights，或按 Head 切分后走 Slice heads + AR/RS 及 A2A + RS(CP*SP)。

03 · LINEAR ATTENTION & STATE

线性层权重与状态扩维切分

通过 PCPColumnParallelLinear 与 PCPRowParallelLinear，将线性注意力（如 KDA）的投影权重与常驻 SSM 状态按 TP × PCP 切分。

显存组成项 纯 PCP 默认行为 开启 TP × PCP 切分后 进一步叠加 DCP 后
Prefill 激活显存 降为 1 / PCP 保持 1 / PCP（开启 SP 进一步降为 1 / (PCP×TP)） 保持 1 / PCP
Embedding / LM Head / o_proj 仅按 1 / TP 切分（PCP 间复制） 按 1 / (TP × PCP) 切分 按 1 / (TP × PCP) 切分
Attention 主 KV Cache 各 PCP Rank 完整保存（1 / TP） 各 PCP Rank 完整保存（1 / TP） 按 1 / DCP 交错分片（最高 TP×PCP）
