PCP 与 DCP：算力切分 vs 显存切分

PCP 切分输入序列算力，DCP 复用现有进程组切分 Attention KV Cache 显存

PCP (Prefill Context Parallel) 切算力 · 降 TTFT

按 DualChunkSwap 头尾对称切分长 Prefill 输入序列，扩展 World Size 为 PCP × TP。

DCP (Decode Context Parallel) 切显存 · 降 TPOT

复用 PCP / TP 进程组，默认将所有 Attention KV Cache（含主 KV 与 Indexer）交错分片（1/DCP）。

DCP ①：Virtual Block 与交错 Slot Mapping

默认切分所有 Attention KV Cache：通过 Virtual Block 跨卡交错落盘，非归属 Rank 写 -1

交错映射公式（block_size % I == 0）

VBlock = block_size × DCP  |  target_rank = ((pos % VBlock) // I) % DCP

Attention KV 默认全切分 (AttentionSpec.dcp_sharded = True)

Full Attention、主 KV 及 Indexer 默认均按 DCP 切分；非序列状态按 Group 设为 False。

DCP ②：Decode 局部注意力与 dcp_a2a_fused

收集完整 Query Heads → 对本地 1/DCP KV 分片算局部 Attention → All2All LSE 加权归并

1. Query Gather / Replicate

跨 DCP 收集完整 Q Heads（DCP==PCP 时免通信）。

2. 无损 LSE 打包 All2All

Triton 打包 BF16 O_j 与 FP32 LSE_j 单次 All2All。

3. LSE 稳定加权归并

w_j = exp(L_j - max L)  |  O = Σ(w_j·O_j) / Σw_j

DCP ③：Chunked Prefill 与 Sparse Indexer 协同

Full Attention / Dense MLA 分块还原历史 KV；稀疏注意力支持 Indexer 与主 KV 同步切分或压缩复制

Full Attention / Dense MLA：分块 Workspace AllGather

按 lcm(block_size, I×DCP) 划窗收集历史 KV，经 kv_rank_offsets 还原顺序。

Sparse Attention：Sharded vs Replicated Indexer

默认与主 KV 同步按 DCP 切分（基数排序归并 Top-K）；高倍压缩池（如 4:1 KPool）可全卡复制。

DCP ④：History / Current 拆流通信重叠

MTP 多 Token 因果 Decode 下，将历史 KV 的 All2All 通信与当前步 KV 计算并行

1. 为什么要拆分？

历史 KV 已按 DCP 分片，当前步新 KV 本地完整持有。

2. 双流隐藏 All2All

通信流异步执行 History All2All，与主流 Current 并行。

3. 单次 LSE 归一化

fused_dcp_lse_combine 一次性归约 History 与 Current。

PCP ①：MRV2 单步 Batch 生命周期

PCP ②：DualChunkSwap 头尾对称切分

切分为 2P 个 Chunk，Rank r 取 (r, 2P-1-r) 展开为 2 条独立虚拟请求段

2x 独立虚拟请求段 (RankSegment)

Head 与 Tail 作为两条独立虚拟请求行，各自携带真实 positions 与 num_computed_tokens。

短请求自动复制 (replicated_requests)

PCP+DCP 下若请求不够分满 2P 个 Chunk，自动全卡复制以保证集合通信步调一致。

PCP ③：Prefill 与 Chunked Prefill 的 KV 同步

计算本地 1/PCP Query 的同时跨 PCP Group AllGather 当前步新 KV，通过 gathered_kv_slot_mappings 落盘

普通 Prefill 路径

计算本地 Q_local / KV_local → PCP AllGather 汇聚新 KV → 按 padded_gather_idx 落盘。

Chunked Prefill / Prefix Cache 路径

DCP=1 时各卡持有完整历史 KV，直接读取本地 Prefix KV 与当前步 Gather 的新 KV 拼接计算。

PCP ④：Decode 请求分配与 TP × PCP 权重切分

利用 PCP 引入的额外 Rank 分摊 Decode 请求计算与常驻权重显存

Decode Request Sharding vs Replicated Decode

PCP>1, DCP=1 下按 decode_ordinal % PCP 轮询切分；叠加 DCP>1 或跨卡状态时保持复制。

常驻权重跨 TP × PCP 切分

默认开启 Embedding、LM Head 及 SFA/DSA o_proj 的跨 PCP 权重切分，释放单卡 HBM。

PCP + DCP 叠加：算力与显存双重切分

在 TP × PCP 网格上复用进程组建 DCP（DCP = PCP 或 DCP = TP × PCP）

PCP 切计算，只有 DCP 切 KV Cache

• 逻辑 DCP 组按 flat_idx = tp_rank * PCP + pcp_rank 组建（先跨 PCP，再跨 TP）。
• Prefill 阶段仅满足 (pos // 128) % DCP == dcp_local_rank 的 Token 写入物理 Slot，其余写 -1。

[示例：TP=2, PCP=2, DCP=4]

TP Groups  : [0, 1], [2, 3]
PCP Groups : [0, 2], [1, 3]
Logical DCP: [0, 2, 1, 3] (PCP-first)
HCCL Sorted: [0, 1, 2, 3] (dcp_collective_rank_order)

Stacked Prefill：统一发送计划 + 掩码落盘

• 当前步新 KV：build_pcp_ordered_slot_mapping 按 padded_gather_idx 重排全局 Slot，过滤 Padding。
• 历史 Cached KV：基于 global_batch 生成统一的 DCP AllGather 发送上界，接收后按本分片区间切片消费。

Stacked Decode：两级融合归并 dcp_a2a_fused(tp, pcp)

• 若 DCP == PCP：同组 Q Heads 已一致，免 Gather Q，直接跨 PCP 归并 (O, LSE)。
• 若 DCP == TP × PCP：仅在 tp_group 内 Gather Q Heads，算完后由 dcp_a2a_fused(..., tp_group, pcp_group) 一步完成跨 TP Scatter 与跨 PCP LSE 归并！

GLM-5.3-Flash 混合架构与 CP 职责拆解

45 层主干（34 层 KDA + 11 层 NoPE SFA/KPool + mHC + MoE）与 5 组 Cache 存储契约

34 LAYERS · KDA

KDA 线性注意力

64 Heads 与 SSM 状态按 TP×PCP 切分；Prefill 先 AllGather 还原因果顺序，输出经 ReduceScatter 切回本地。

11 LAYERS · KPOOL

KPool 4:1 索引器

压缩池与 FP32 Tail Ring 全卡复制；Prefill 用 all_gather_async 重叠本地 Query 投影，选 Top-2051。

11 LAYERS · NoPE SFA

NoPE SFA 主注意力

512 维 Latent KV 按 DCP 交错切分（1/DCP）；Decode 用 sparse_index_remap + dcp_a2a_fused。

45 LAYERS · mHC & MoE

mHC & EP MoE

4 条残差流与 288 专家 MoE 保持在 PCP 本地视图 [T_local, 4096] 上执行，与 EP All2All 正交。

部署选型与未来演进规划

GLM-5.3-Flash 推荐部署拓扑与 vLLM-Ascend 下一步优化方向

1. GLM-5.3-Flash 典型部署拓扑

• PD 分离 Prefill 节点：DP1 + TP1 + PCP8 + EP8（16 个 DualChunk 并行 + KDA/词表切分）。
• PD 分离 Decode 节点：DP8 + TP1 + PCP1 + EP8（FULL_DECODE_ONLY + MTP5 + ReplaySSM）。
• 超长上下文混部（128K ~ 1M+）：开启 DCP（I == block_size == 128）消除主 KV 冗余。

2. 未来演进规划（Roadmap）

• KPool / 线性层 PCP Decode Sharding：支持跨 PCP Rank 的 Recurrent State 归属管理。
• BlockTable 对齐 vLLM #57169：收敛为 Manager-Block 粒度，Kernel-Block 下沉至 AttentionGroup。
• 算子融合与 Dynamic CP：拓展 dcp_q_replicate 与按序列长度动态组建 CP 通信组。

短序列 (4K ~ 32K)

优先标准 DP / TP，无需开启 CP。

中长序列 (32K ~ 256K)

开启 PCP 压降首字时延 TTFT。

超长序列 (128K ~ 1M+)

开启 DCP 或 PCP + DCP 释放 KV 容量。

    def _dcp_all_gather_fragments(self, *tensors: torch.Tensor, dim: int) -> tuple[torch.Tensor, ...]:
        if not tensors:
            return ()
        split_sizes = [tensor.shape[-1] for tensor in tensors]
        pcp_group = getattr(self, "pcp_group", None)
        if dim == 1 and pcp_group is not None and pcp_group.world_size > 1:
            # Query heads are replicated across PCP ranks. Gather only
            # distinct TP heads when DCP spans the full TP x PCP domain.
            if self.dcp_size == pcp_group.world_size:
                return tensors
            gathered = self.tp_group.all_gather(torch.cat(tensors, dim=-1).contiguous(), dim=dim)
        else:
            gathered = self._dcp_all_gather(torch.cat(tensors, dim=-1), dim)
        return torch.split(gathered, split_sizes, dim=-1)

    def replicated_requests(
        self, num_scheduled_tokens: np.ndarray, is_prefilling: np.ndarray
    ) -> np.ndarray:
        """Per global request, whether every PCP rank gets the whole query."""
        num_chunks = 2 * self.pcp_world_size
        query_lens = np.asarray(num_scheduled_tokens, dtype=np.int64)
        replicated = ~np.asarray(is_prefilling, dtype=np.bool_)
        if self.dcp_world_size > 1:
            chunk_sizes = (query_lens + num_chunks - 1) // num_chunks
            drops_a_chunk = (num_chunks - 1) * chunk_sizes >= query_lens
            replicated |= drops_a_chunk
        return replicated

    def _iter_rank_chunks(self, rank: int, num_scheduled_tokens: np.ndarray, is_prefilling: np.ndarray):
        decode_ordinal = 0
        num_chunks = 2 * self.pcp_world_size
        replicated = self.replicated_requests(num_scheduled_tokens, is_prefilling)
        for global_batch_req_idx, num_tokens in enumerate(num_scheduled_tokens):
            query_len = int(num_tokens)
            if query_len == 0:
                continue
            if not replicated[global_batch_req_idx]:
                chunk_size = (query_len + num_chunks - 1) // num_chunks
                chunk_indices = (rank, num_chunks - 1 - rank)
            elif self.shard_decode_requests:
                chunk_size = query_len
                owner_rank = decode_ordinal % self.pcp_world_size
                decode_ordinal += 1
                chunk_indices = (0,) if rank == owner_rank else ()
            else:  # DCP requires decode queries on every participating rank.
                chunk_size = query_len
                chunk_indices = (0,)

        # PCP=2 example:
        #   global batch:       [A B C D E F G]
        #   rank 0 / rank 1:    [A B G] / [C D E F]
        #   padded gathered:    [A B G _ | C D E F]
        #   hidden_restore_idx: [0, 1, 4, 5, 6, 7, 2]
        #   padded_gather_idx:  [0, 1, 6, 0, 2, 3, 4, 5]
        # Therefore global = gathered[hidden_restore_idx] and
        # padded_gathered = global[padded_gather_idx].
        hidden_restore_idx = np.empty(int(query_start_loc_np[-1]), dtype=np.int64)
        ...
        for rank, segments in enumerate(segments_by_rank):
            expanded_rank_offset = rank * padded_num_tokens
            for segment in segments:
                padded_gathered_slice = slice(
                    expanded_rank_offset + segment.rank_local_batch_slice.start,
                    expanded_rank_offset + segment.rank_local_batch_slice.stop,
                )
                padded_gather_idx[padded_gathered_slice] = np.arange(
                    segment.global_batch_slice.start,
                    segment.global_batch_slice.stop,
                    dtype=np.int64,
                )
                is_sharded_decode = (
                    not bool(is_prefilling[segment.global_batch_req_idx])
                    and self.shard_decode_requests
                )
                if replicated[segment.global_batch_req_idx] and not is_sharded_decode and rank != 0:
                    continue
                gathered_kv_write_mask[padded_gathered_slice] = True
                hidden_restore_idx[segment.global_batch_slice] = np.arange(
                    padded_gathered_slice.start,
                    padded_gathered_slice.stop,
                    dtype=np.int64,
                )
